## Projetos em destaque

### TravelBroker

Aplicação web desenvolvida para **validação, correção e monitoramento de viagens de ônibus**, com foco em resolver inconsistências operacionais relacionadas a horários de saídas automáticas.

**Principais pontos do projeto:**

* Upload e leitura de planilhas Excel.
* Validação de viagens com base em regras operacionais.
* Integração com API externa para consulta e correção de dados.
* Dashboard com gráficos mensais e indicadores por linha.
* Autenticação com Firebase.
* Uso de Firestore para métricas e controle operacional.

**Tecnologias:** React, TypeScript, Vite, Firebase, Firestore, Axios, Chart.js, Tailwind CSS.

[Ver repositório](https://github.com/Mateusdev3/TravelBroker)

### WebQuery

Ferramenta de console criada para **automatizar buscas em lote de relatórios e arquivos em APIs ou sistemas corporativos**.

O projeto resolve um problema comum em empresas: a necessidade de realizar inúmeras buscas manuais para baixar arquivos como **PDF, XLSX, KML, XML, JSON** e outros formatos. Em um uso real, foi utilizado para buscar aproximadamente **700 arquivos KML em poucos segundos**, substituindo uma tarefa manual que havia levado mais de **2 meses**.

**Principais pontos do projeto:**

* Cadastro e execução de buscas salvas.
* Leitura de parâmetros a partir de planilhas Excel.
* Execução de requisições GET e POST.
* Autenticação por Bearer Token.
* Geração automática de arquivos de resultado.
* Suporte a respostas em Base64 e JSON.

**Tecnologias:** C#, .NET, ClosedXML, HttpClient, JSON, Excel.

[Ver repositório](https://github.com/Mateusdev3/WebQuery)

### WebServiceItinerarios

Sistema web para **conferência de itinerários de transporte público** a partir de arquivos KML, realizando comparação geográfica entre o trajeto informado e os dados retornados por uma API externa.

**Principais pontos do projeto:**

* Upload e processamento de arquivos KML.
* Conversão de XML/KML para dados estruturados.
* Consulta de itinerários em API externa.
* Comparação geográfica entre rotas.
* Detecção de desvios acima de um limite definido.
* Visualização dos trajetos em mapa interativo.

**Tecnologias:** Next.js, React, TypeScript, Tailwind CSS, fast-xml-parser, Turf.js, MapLibre GL, React Map GL.

[Ver repositório](https://github.com/Mateusdev3/WebServiceItinerarios)
